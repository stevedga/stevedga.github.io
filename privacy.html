Privacy Policy

For the MESSKAI internal email application. Effective 21 September 2026.

This policy covers one specific application: an internal tool that MESSKAI uses to send email from its own Google account. The application is not offered to the public and has no users other than MESSKAI itself.

What the application accesses

The application requests a single Google API permission:

  • https://www.googleapis.com/auth/gmail.send

This permission allows the application to send email through the Gmail API on behalf of the Google account that authorized it. It does not allow the application to read, search, download, modify, label or delete any message in that mailbox, and it does not give access to Google Contacts, Google Drive, Google Calendar or any other Google service.

Whose account is used

The only account that authorizes this application is a Google account belonging to MESSKAI. The application does not ask anyone else to sign in and does not access any other person's Google account.

What is stored

To stay authorized without signing in repeatedly, the application stores the OAuth refresh token issued by Google. That token is held in access controlled infrastructure under MESSKAI's own control and is not shared with any third party.

The application also keeps a record of the messages it has sent, so that it does not send the same message twice. That record contains the recipient address, the subject, the time of sending and the identifier Google returns for the message.

What is not done with data

  • Data obtained through the Gmail API is not sold.
  • It is not shared with, transferred to, or disclosed to any third party.
  • It is not used for advertising, profiling or any form of marketing analytics.
  • It is not used to train machine learning or AI models.
  • It is not read by humans, except where necessary to resolve a specific technical fault, to comply with applicable law, or where MESSKAI has the account holder's explicit consent.

MESSKAI's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

This website

This site is a set of static pages. It sets no cookies, runs no analytics, includes no tracking scripts, loads no third party resources, and collects nothing from anyone who visits it.

Withdrawing access

The account holder can revoke this application's access at any time from the Google account permissions page at myaccount.google.com/permissions. Revoking access immediately invalidates the stored token and stops the application from sending.

Retention

The stored token is kept only while the application is in use and is destroyed when access is revoked or the application is retired. Send records are kept only as long as they are needed to prevent duplicate sending.

Changes

If the application's permissions or data handling change, this page is updated and the effective date above is changed with it.
